# 🇩🇴 Tres en Raya Quisqueya

**Autor:** Stanley Rosario Hernández

## Descripción
Juego de Tres en Raya hecho con React.js. Dos jugadores (Jugador Quisqueya y Jugador Taíno) se turnan para marcar X y O en un tablero 3x3. El juego detecta al ganador o el empate, permite reiniciar la partida y guarda el estado en el navegador con localStorage.
